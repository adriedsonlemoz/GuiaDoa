# Antropos — estratégias confirmadas da Beta 2.47

Fonte comunitária histórica: `https://dragonsofatlantis.fandom.com/wiki/Anthropus_Camps`.

Nesta versão, os valores de marcha foram fornecidos e **confirmados pelo usuário no jogo mobile atual**. O site comunitário é mantido como referência histórica para siglas, composição dos métodos e avisos de compatibilidade.

## Convenções usadas no GUIA

- LBM → Arqueiros / Longbowmen
- Porters → Carregadores
- AT / ATs → Transportes Blindados / Armored Transports
- SSD → Dragões de Ataque Rápido / Swift Strike Dragons
- BD → Dragões de Combate / Battle Dragons
- FT → Fangtooth (nome PT-BR não confirmado no catálogo atual)
- LJ → Lava Jaws (nome PT-BR não confirmado no catálogo atual)
- GD → Grande Dragão / Great Dragon
- ED → Dragão Elemental / Elemental Dragon
- Met → Metalurgia / Metallurgy
- Med → Medicina / Medicine
- WC → Calibração de Armas / Weapons Calibration
- Drag → Dragoria / Dragonry

## Regras de integridade

- O frontend mobile cadastra somente Antropos Nv. 1–10. O Nv. 11 citado na referência histórica **não é criado**.
- Marchas confirmadas recebem `resultado=sem_perdas`, exceto as duas variantes de SSD no Nv. 9 explicitamente marcadas como `possiveis_perdas`.
- Fangtooth Nv. 4 não possui quantidade na tabela fornecida; o GUIA mantém `quantidade=null` e `resultado=incompleto`, sem inventar valor.
- A recomendação de margem extra de 10% em ATs é exibida como segurança adicional. Quando a marcha oferece Porters ou ATs, use apenas uma das opções.
- O aviso de não misturar tropas de alcance com tropas rápidas corpo a corpo é preservado, assim como o alerta histórico sobre RNG/Dragão do Vento em LBM.
- Nenhum Antropos, tropa ou pesquisa adicional foi criado a partir de dedução.
